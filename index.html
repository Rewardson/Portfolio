Work / Baza

Baza

Baza connects informal workers with clients through trusted discovery, booking workflows, and verification mechanisms.

Project type Research & Product
Status In development
Platform Mobile-first
Trust score

Overview

Baza is designed to help informal workers find consistent work while making it easier for clients to discover trustworthy, verified service providers.

The Problem

  • Informal workers struggle to find reliable client opportunities.
  • Clients find it difficult to identify trustworthy workers.
  • There is limited reputation and verification in informal marketplaces.
  • Job completion and trust are hard to confirm.

The Solution

  • Worker and client discovery with location support.
  • Worker profiles and availability signals.
  • Trust score and ratings for credibility.
  • OTP-based job completion and verification.

How it works

Client searches for worker Views worker profile Reviews reputation Requests service Worker accepts Job completes Client submits rating

Trust system

The trust model focuses on job success, verification, consistency, ratings, and complaint handling rather than vanity metrics.

Key features

  • Worker discovery
  • Client discovery
  • GPS/location-based discovery
  • Booking and availability
  • OTP job completion
  • Ratings and reviews
  • Trust score
  • Verification

Technology

React Native TypeScript Firebase Authentication Cloud Firestore Firebase Storage GPS / location services OTP verification

Challenges

Balancing trust, verification, and usability in an informal worker marketplace required careful design of reputation signals and completion flows.

What I learned

Building Baza reinforced the importance of system design for trust, the value of mobile-first worker discovery, and how verification workflows shape user confidence.

Work / Docket Management

Docket Management System

A digital workflow that helps administrators manage exam dockets, fees, and QR-based lecturer verification.

Project type Research
Status Research project
Platform Web
QR verification

Overview

The Docket Management System brings exam docket tracking, fee verification, and lecturer confirmation into a clean digital process.

The Problem

  • Managing exam dockets manually leads to lost records and extra administrative friction.
  • Tracking student fees and verifying exam access is time-intensive.
  • Lecturers need a reliable way to confirm student documents.

The Solution

  • Centralize exam docket records online.
  • Surface fee status clearly for administrators.
  • Enable QR-based verification for expedited lecturer confirmations.

Key features

  • Exam docket tracking
  • Fee workflow visibility
  • QR verification for lecturers
  • Academic status reporting

Technology

JavaScript Web

Project status

Challenges

What I learned
